# Battleship (cmd)
-# Command line Battleship Game

## Launch

The program may be launched using `run.bat` or by entering `python3 src/launch.py` into a terminal.

When you run the program, you will be given the following options:

 - Play Battleship

A typical game of battleship, with you against a CPU.
 - Play Battleship (Experimental)

Experimental battleship game that can expand to include many players and CPUs.
 - Quit

## Gameplay

Follows standard battleship rules.
